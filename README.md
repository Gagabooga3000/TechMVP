# TechMVP — лендинг по ТЗ (готов к заливке)

Этот проект содержит готовый одностраничный лендинг по вашему ТЗ: все обязательные блоки, 3+ конверсионных элемента, адаптивность и быстрая загрузка.

Состав:
- `index.html` — разметка и контент (RU)
- `styles.css` — стили, адаптив
- `script.js` — плавная прокрутка, мобильное меню, FAQ-аккордеон, UX формы

## Быстрый запуск локально
Откройте `index.html` в браузере (двойной клик).

## Хостинг как статические файлы
1) Залейте папку `landing/` (все файлы) на любой хостинг статики:
- GitHub Pages, Netlify, Vercel, ваш VPS/хостинг
2) Убедитесь, что корневой файл — `index.html`.

Форма отправляется через Formspree (демо-эндпоинт в `index.html`, секция Signup). Замените на свой endpoint при необходимости.

## Авторизация и профиль (PHP + MySQL)
Для использования входа/регистрации/профиля нужен PHP-хостинг (Apache/Nginx + PHP 8.x) и MySQL.

Файлы бэкенда:
- `backend/config.php` — подключение к БД (PDO) и функции сессий
- `backend/db.sql` — схема БД (таблица `users`)
- `login.php` — вход
- `register.php` — регистрация
- `logout.php` — выход
- `profile.php` — профиль (просмотр/редактирование)

Шаги настройки через phpMyAdmin:
1) Зайдите в phpMyAdmin под пользователем `u3085178_default`.
2) Выберите БД `u3085178_default` (или создайте её, если нужно).
3) Импортируйте файл `landing/backend/db.sql` (вкладка Import → выберите файл → Go).
4) В `landing/backend/config.php` проверьте/замените параметры подключения при необходимости.

Размещение на PHP-хостинге:
- Залейте всю папку `landing/` на сервер (в веб-корень или подкаталог).
- Откройте `/register.php` для создания первого пользователя.
- Навигация «Войти/Регистрация» уже добавлена в шапку `index.html`.

## Воссоздание на Flexbe (требование организаторов)
Flexbe — визуальный редактор, импорт HTML недоступен. Ниже — точная структура блоков и тексты для быстрого переноса:

1. Header
- Логотип: текст «TechMVP» + иконка (можно выбрать встроенную)
- Меню: Главная (#hero), О продукте (#about), Преимущества (#benefits), Тарифы (#pricing), Контакты (#contacts)

2. Первый экран (Hero)
- Заголовок: «Автоматизируйте запуск MVP за 5 минут»
- Подзаголовок: «TechMVP помогает студентам… без кода.»
- Кнопка (главная CTA): «Попробовать бесплатно» → якорь #signup
- Доп. кнопка: «Запросить демо-доступ» → якорь #demo (можно также на #signup)
- Визуал: скрин/схема продукта (используйте блок «Изображение»)

3. Проблема / Решение
- Два текстовых блока «Проблема» и «Решение» (см. тексты из `index.html`)

4. Как это работает / Преимущества
- 4 карточки с иконкой, заголовком и текстом (Быстрый старт, Встроенная аналитика, Интеграции, Надёжность)

5. Тарифы
- Две карточки планов: «Базовый (0₽/14 дней)» и «Профессиональный (490₽/мес)»
- Списки возможностей и кнопки: «Начать бесплатно», «Выбрать тариф» → #signup
- Отметка «Рекомендуем» на Pro

6. Социальное доказательство
- 2 отзыва (можно смоделировать под чемпионат)

7. FAQ
- 3–4 вопроса-ответа. Сделайте их сворачиваемыми (аккордеон Flexbe)

8. Финальный CTA + форма
- Заголовок: «Готовы проверить гипотезу?»
- Текст-аргумент: «Подпишитесь, чтобы первыми получить доступ…»
- Кнопка «Сравнить тарифы» → #pricing
- Форма: поле e-mail + кнопка «Получить доступ» (привяжите к почте/CRM или Telegram через интеграции Flexbe)

9. Footer
- Логотип и © год
- Контакты: team@example.com, Telegram (`https://t.me/yourteam`)
- Ссылка «Политика конфиденциальности» (создайте отдельную страницу или всплывающее окно)

10. Доп. конверсия
- Закреплённая кнопка «Заказать звонок» (в Flexbe — закреплённая кнопка снизу справа) → ссылка на Telegram/форму

### Советы по Flexbe
- Цвета: используйте основную #00D3A7, фон тёмный, текст светлый
- Шрифты: Inter или аналогичный без засечек
- Отступы: держите воздух, не менее 60–80px между секциями на десктопе
- Адаптив: проверьте 320–1440px, чтобы кнопки не переносили важные слова

## Кастомизация под ваш MVP
Замените тексты УТП, тарифов и отзывов под ваш продукт. При необходимости добавьте логотипы партнёров и счётчики (Яндекс.Метрика, GA4) через Flexbe или через статический хостинг и теги скриптов.

## Лицензия
Свободно используйте и модифицируйте в рамках кейс-чемпионата.
