# Руководство по развертыванию TechMVP

## Требования

- PHP 8.0 или выше
- MySQL 5.7+ или MariaDB 10.3+
- Apache/Nginx с mod_rewrite
- SSL сертификат (рекомендуется)

## Установка

### 1. Загрузка файлов

Загрузите все файлы на сервер в корневую директорию или подкаталог.

### 2. Настройка базы данных

1. Создайте базу данных MySQL
2. Импортируйте схему: `backend/db.sql`
3. Обновите данные подключения в `backend/config.php`:
   ```php
   $DB_HOST = 'localhost';
   $DB_NAME = 'your_database';
   $DB_USER = 'your_user';
   $DB_PASS = 'your_password';
   ```

### 3. Настройка прав доступа

```bash
chmod 644 backend/config.php
chmod 755 backend/
```

### 4. Настройка cron (опционально)

Для автоматической проверки истечения подписок добавьте в crontab:

```bash
0 0 * * * php /path/to/backend/check_expired_subscriptions.php
```

### 5. Настройка .htaccess

Убедитесь, что mod_rewrite включен в Apache. Для Nginx настройте соответствующие правила.

## Безопасность

1. **Защита config.php**: Убедитесь, что `backend/config.php` недоступен через веб-интерфейс
2. **CSRF защита**: Уже реализована во всех формах
3. **SQL инъекции**: Используются prepared statements
4. **XSS защита**: Все пользовательские данные экранируются через `htmlspecialchars()`

## Интеграция платежей

Для подключения реальных платежей:

1. Зарегистрируйтесь в платежной системе (ЮKassa, Stripe и т.д.)
2. Получите API ключи
3. Обновите `payment.php` для интеграции с API
4. Настройте webhook для обработки уведомлений о платежах

## Email-уведомления

Для отправки email:

1. Настройте SMTP в PHP (через `php.ini` или библиотеку PHPMailer)
2. Добавьте функции отправки в соответствующие места:
   - Регистрация
   - Восстановление пароля
   - Истечение подписки
   - Новые заявки (опционально)

## Резервное копирование

Рекомендуется настроить автоматическое резервное копирование:

```bash
# Пример скрипта бэкапа
mysqldump -u user -p database > backup_$(date +%Y%m%d).sql
```

## Мониторинг

- Настройте логирование ошибок PHP
- Мониторьте использование дискового пространства
- Отслеживайте производительность базы данных

## Обновление

При обновлении:

1. Сделайте резервную копию базы данных
2. Загрузите новые файлы
3. Выполните миграции БД (если есть)
4. Очистите кеш браузера
